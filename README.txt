Memory App

Use the same private sync code on both devices. In Settings, check the last
successful sync before switching devices and wait for pending edits to save.
The app continues locally when offline and retries when it reconnects.

For a private GitHub sentence catalog, ChatGPT and Codex access, private
change proposals, and backup instructions, see docs/private-sentence-library.md.

Browser and unit tests use synthetic profiles. Run npm ci and then npm test.
