# 답안 입력 중 학습 화면 이탈 조사

조사 기준: `5e18b7383fa5bb5f1e73c6be17d9d971f253154a` 이후 로컬 수정. 실제 사용자 저장소와 Cloudflare Worker는 변경하지 않았다.

## 재현한 원인

1. `sync-bootstrap.js`의 `startPolling()`은 20초마다 원격 스냅샷을 읽고 차이가 있으면 `applyRemote()` 후 `window.location.reload()`를 실행했다. 학습 상태 검사가 없고 답안 입력은 동기화 데이터(`DATA_KEYS`)를 변경하지 않으므로, 입력 중에도 `localDirty === false`였다. 변경된 원격 스냅샷을 응답시키면 입력 중 문서가 새로 로드되는 것을 격리 Chromium에서 재현했다. 홈에서 시작된 요청의 응답이 학습 시작 후 도착하는 경합도 가능했다.
2. `app.js`의 서비스워커 `controllerchange`는 조건 없이 문서를 새로 로드했다. 입력 중 해당 이벤트를 전달했을 때 같은 문서가 사라지는 것을 재현했다.
3. 문제/대기열/입력/채점 상태는 함수 내부 메모리에만 존재했다. 시작 시 `loadAll()`은 카드와 설정만 읽고, HTML은 메인화면을 기본으로 표시했다. 따라서 위 새로고침 및 일반 새로고침에서 학습 화면이 메인화면으로 바뀌었다. 미제출 답안이 있는 상태에서 재로드하여 재현했다.

이는 증상과 일치하는 실제 코드 경로와 재현 결과다. 사용자 아이폰의 당시 로그가 없으므로, 개별 발생 건이 동기화·PWA 업데이트·Safari 프로세스 재시작 중 어느 것이었는지는 단정하지 않는다. iOS의 실제 프로세스 회수나 화면 잠금은 실기기로 직접 재현하지 않았다.

## 복원과 데이터 보존

- `memory_study_session_v1`은 로컬 전용 추가 키다. 기존 카드·SRS·오답 이력·백업 형식과 동기화 `DATA_KEYS`는 변경하지 않았다.
- 현재 카드 ID, 입력 답안과 선택 범위, 제출/확정 여부, 진행 수·연속 정답, 최초/재도전 대기열, 재출제 1·2단계와 대기열, 체크 표시, 연습 모드 및 결과 UI를 저장한다.
- 정상 완료와 확인된 취소는 종료 표식을 저장한다. 종료된 세션이 다음 시작에서 부활하지 않는다.
- 채점 변경을 세션 체크포인트의 쓰기 기록에 먼저 넣고, 그 뒤 기존 SRS/오답 이력/설정 저장소에 반영한다. 재시작 시 미완료 쓰기는 이전 값이 그대로인 경우에만 복구한다. 이미 반영된 쓰기는 멱등적으로 처리하고, 다른 변경과 충돌하면 덮어쓰지 않는다. 채점 함수 자체를 다시 실행하지 않는다.
- 기본 저장소 오류 시 현재 탭의 `sessionStorage`에도 보관하고 상태 메시지를 표시한다. 두 저장소가 모두 쓰기 불가능하거나 사용자가 브라우저 저장소를 삭제한 경우까지 복구를 보장할 수는 없다.
- `memory_study_diagnostics_v1`에는 최근 30개의 이벤트 코드·시간·재출제 단계·진행 수만 저장한다. 문장·입력 답안·동기화 코드는 기록하지 않는다. 진단 및 체크포인트 키는 외부 전송하지 않는다.

## 검증

`npm test`로 단위 테스트와 격리 Chromium 테스트를 실행한다. 추가 회귀 테스트는 `tests/browser/session-recovery.spec.js`에 있다. 동기화 응답은 모두 로컬 모의 응답이며 실제 Worker에는 접근하지 않는다. 사용자 브라우저 프로필도 사용하지 않는다.

검증 범위: 원격 변경 폴링, 지연 응답 경합, 재로드 시 로컬 우선 복원, 입력 답안 복원, PWA 컨트롤러 이벤트, 미확정 결과 및 재출제 1·2단계, 저장 실패 후 SRS/오답 중복 방지, 화면 숨김/복귀 및 동기화 실패, 빠른 터치·스크롤·조합 입력·중복 클릭, 확인된 취소와 오래된 콜백, 확정 직후 전환 도중 재로드, 새 탭과 뒤로가기 복원. 기존 채점·문제 편집·재출제 회귀 테스트도 함께 실행한다.

최종 검증 결과: `npm test` 통과. 단위 테스트와 Chromium 브라우저 테스트 29개(기존 18개 + 모바일 세션 복구 11개)가 모두 통과했다. `node --check app.js`, `node --check sync-bootstrap.js`, `git diff --check`도 통과했다.

초기 조사·수정 단계에서는 commit/push 및 배포하지 않았으며, 이후 사용자의 명시적인 요청에 따라 배포 절차를 진행한다. 기존 미추적 파일 2개의 SHA-256은 작업 전과 동일하다.
