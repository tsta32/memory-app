# 영어업무(일반) 200문장 우선순위 평가

사용 빈도에 관한 코퍼스 통계는 사용하지 않았다. 아래 빈도·활용도는 일반적인 업무 영어 사용 관행에 따른 추정 평가이며 실측 순위가 아니다. 개수를 먼저 정하지 않고 영어·한국어 번역·저장 문맥을 대조해 발언 목적별로 비교했다.

선정 조건: ① 업무 대화에서 자주 쓰이는 것으로 평가 ② 소통상 중요하고 간단한 대체가 어려움 ③ 여러 상황·목적에 재사용 가능. 필수는 하나 이상의 조건을 충족한다. 쉬움·짧음은 선정 근거로 사용하지 않았다.

유사 목적 그룹당 필수 대표는 하나다. 시간 수락(82)과 거절(83), 지연 통보(165)와 기한 연장 요청(171), 진행 동의 요청(189)과 정식 승인 요청(194)은 상대에게 요구하는 반응이 달라 서로 대체되는 중복으로 보지 않았다. 모든 그룹에 필수를 억지로 두지는 않았다.

분류: 필수 39개 / 중요 128개 / 보조 33개. 누락 0개.

## 데이터와 학습 정책

`business-priorities.js`와 원본 JSON에 200개 분류를 저장한다. 번호는 원본 감사용이며 사용자 카드의 ID나 배열 위치로 연결하지 않는다. 대상 챕터의 기존 키 → 영어 원문 정규화 일치 → 유일하고 충돌 없는 기존 한국어/문맥 일치 순으로 원본을 식별한다. 식별 후 영구 `businessTemplateKey`를 보관해 이후 문구 수정과 순서·ID 변화에도 연결을 유지한다. 사용자 등급과 모든 문구·학습 필드는 덮어쓰지 않는다. 모든 식별 정보가 바뀐 기존 카드는 억지 매칭하지 않고 미분류로 표시해 직접 등급을 선택하게 한다. 다른 챕터에 자동 등급을 붙이지 않는다.

`firstCorrectAt`은 최초 시험의 자동 정답 또는 수동 정답 변경 확정 시에만 기록한다. 재출제·세션 내 재도전 정답으로 만들지 않는다. 기존 `everAnswered`는 오답에도 설정되므로 정답 근거가 아니다. 과거 상태만으로 정답을 추정하지 않으며 기존 SRS·오답·총계를 초기화하지 않는다. 연습 모드 최초 시험 정답도 이 새 사실 기록은 남기되 기존 SRS 일정은 바꾸지 않는다.

자동 학습은 선택 범위의 필수 현재 복습 → 최초 정답 미완료 필수 → 중요 현재 복습 → 최초 정답 미완료 중요 순이다. 미완료 필수가 하나라도 있거나 현재 필수 복습이 남으면 중요를 선택하지 않는다. SRS가 미래인 미완료 카드는 복습 기한을 앞당기지 않으며 화면에 대기 사유를 표시한다. 이미 필수가 모두 최초 정답을 받은 상태라면 미래 복습은 중요 진입을 막지 않는다. 과거 정답 불명 카드는 등급 선택 연습으로 최초 정답을 확인할 수 있다.

보조는 자동 출제에서 제외하고 등급 선택 또는 선택 카드 시험에서만 학습한다. 카테고리·등급·북마크·오답 조건·선택 카드 범위를 보존한다. 다른 카테고리와 미분류 카드는 기존 SRS 선택 규칙을 유지한다. 새 세션 생성 때 현재 시각으로 다시 우선순위를 계산하며 진행 중인 문제·순서·재출제 큐는 재정렬하지 않는다. 진행 중 세션을 새 버전에서 복원해도 그 큐를 유지한다. 백업·복원·동기화는 카드 객체의 새 필드를 그대로 보관한다.
